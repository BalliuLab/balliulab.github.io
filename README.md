# Balliu Lab @ UCLA — website

Source for <https://brunildaballiu.github.io>.

A minimal, static, multi-page site (client-side routing). No build step: GitHub
Pages serves the files directly because of the `.nojekyll` file.

- `index.html` — the whole site (markup, styles, and the small page-switching script)
- `media/` — images (research figures and member photos)

To edit: change `index.html` (and add images to `media/`), commit to `main`, and
GitHub Pages publishes within a minute or two.

The previous AcademicPages version is preserved on the `backup-academicpages` branch.
